# Желаемая дата, срочные заказы, простая форма и полная правка заказа в Telegram

Дата: 2026-11-15. Статус: согласовано.

## Зачем

- Клиенты не указывают, к какому дню нужен брелок: это выясняется в переписке, а дата нигде не фиксируется.
- Менеджер не может исправить в заказе ничего, кроме способа доставки: имя, телефон, адрес остаются как ввёл клиент,
  поправки живут только в заметках. При смене доставки бот ждёт адрес строго в порядке «индекс, город, район, улица»,
  и при другом порядке поля путаются (реальный случай #YRQ5EQ: телефон попал в «Улицу»).
- Клиенты ошибаются в форме (телефоны в разных форматах, район и город в произвольном виде), автозаполнение браузера
  подставляет чужие или неверные данные.

## Цели

1. В форме обязательное поле «когда нужен брелок», варианты зависят от способа получения.
2. Срочный заказ «на сегодня» за +100 лей: только самовывоз или такси по Кишинёву (такси оплачивает клиент).
3. Форма с минимумом ручного ввода и без автозаполнения.
4. Менеджер меняет любые данные заказа (имя, телефон, дату, срочность, способ получения, адрес) одной кнопкой
   «✏️ Изменить» в Telegram, получая текущие данные уже разложенными по полям.

## Не цели

- База данных заказов (отдельная задача из отчёта за ноябрь).
- Страница редактирования на сайте / Mini App (вариант B, отложен; можно добавить позже поверх).
- Изменение фото, PDF-макета, цен на брелоки.

## Анти-цели (провал, даже если «работает»)

- Клиент видит дату или срок, который вы не выполните (например, почту «к завтра»).
- Срочность выглядит гарантированной до подтверждения менеджером.
- Правка в боте теряет данные заказа: второй брелок, источник, заметки, историю.
- Форма стала длиннее или сложнее для обычного заказа «самовывоз, не срочно».

## Варианты правки в Telegram (выбран A)

- **A. Шаблон в чате (выбран).** Кнопка «✏️ Изменить» → бот присылает все поля заказа блоком, который копируется
  одним нажатием. Менеджер исправляет строки и отправляет ответом; бот разбирает по названиям полей.
  Всё в чате, быстро сделать. Минус — шаг «скопировать» (Telegram не даёт боту вставить текст в поле ввода).
- **B. Страница на сайте с заполненной формой.** Удобнее, но примерно вдвое больше работы, нужна защищённая ссылка,
  правка уходит из чата в браузер. Отложен.
- **Mini App в Telegram.** По сути B, плюс настройка через BotFather. Отброшен.

## Правила дат (решено с владельцем)

Все расчёты — по времени Кишинёва (`Europe/Chisinau`), одной общей функцией на клиенте и сервере (`lib/delivery-dates.ts`).

- **Самовывоз:** ближайшая обычная дата — завтра (изготовление минимум сутки). Любой день недели.
- **Срочно («сегодня»):** +100 лей, только самовывоз или такси по Кишинёву. Подпись: «Подтвердим в чате, успеваем ли».
  Вариант скрыт после 18:00 по Кишинёву (самовывоз ежедневно 12:00–21:00); сервер принимает срочный заказ до 18:30 (запас на тех, кто открыл форму до 18:00), позже — ошибка с предложением выбрать завтра.
- **Почта (Poșta Moldovei и Nova Poshta):** клиент выбирает дату, к которой хочет *получить* посылку.
  Ближайшая = дата заказа + 2 рабочих дня (изготовление и отправка, пн–пт) + 3 календарных дня в пути.
  Примеры: заказ в пн → отправка до ср → получение с сб; заказ в пт → отправка до вт → получение с пт.
  Срочного варианта нет. Подсказка: «Изготовим и отправим за 1–2 рабочих дня, почта идёт до 3 дней».
- Для почты в Telegram показываем и «отправить до» (дата заказа + 2 рабочих дня).
- Сервер повторно проверяет дату: не раньше ближайшей для способа, не позже чем через 90 дней; срочно + почта → ошибка.

## Форма (components/OrderModal.tsx)

Порядок: Имя → Телефон → Способ получения (Самовывоз · Poșta Moldovei · Nova Poshta) → Дата → Второй брелок → Согласия → «Заказать».

**Дата**, под выбранный способ (кнопки-«таблетки», календарь только по «Другая дата»):

```
Самовывоз:  Когда заберёте?
            [ Завтра, сб 16.11 ] [ Послезавтра, вс 17.11 ] [ Другая дата 📅 ]
            [ ⚡ Сегодня — срочно, +100 лей ]   Подтвердим в чате, успеваем ли

            если «Сегодня»:  Как получите?
                             ( ) Заберу сам — Bernardazzi 64
                             ( ) Такси по Кишинёву — оплачиваете водителю
                                 Адрес: [______________]

Почта:      К какой дате хотите получить?
            Изготовим и отправим за 1–2 рабочих дня, почта идёт до 3 дней
            [ чт 20.11 ] [ пт 21.11 ] [ Другая дата 📅 ]
```

Смена способа сбрасывает выбранную дату, если она стала недоступной.

**Меньше ошибок** (решения исполнителя, подтверждены владельцем в обсуждении):
- Автозаполнение выключено во всех полях (`autoComplete="off"` и нестандартные `name`, чтобы Chrome не угадывал поля).
- Телефон: неизменяемый префикс `+373`, ввод 8 цифр; ведущий `0` (`069…`) и вставка полного `+373…` нормализуются.
  Ошибка простыми словами («в номере 7 цифр, нужно 8»).
- Индекс: только 4 цифры, подсказка `MD-____`.
- Район: выбор из списка (районы Молдовы + Кишинёв, Бельцы, АТО Гагаузия, Тирасполь/Бендеры/левобережье),
  названия по-румынски и по-русски.
- Ошибки показываются у поля сразу, тексты на языке интерфейса (RU/RO).

## Заказ в Telegram (lib/telegram-orders.ts, app/api/order/route.ts)

```
🔥 Новый заказ #ABC123
⚡ СРОЧНО +100 лей · на сегодня 15.11          ← только у срочных, сразу под заголовком
👤 Клиент: …
📞 Тел: +373 …
📅 Нужен к: пт 21.11 · отправить до: ср 19.11  ← «отправить до» только для почты
🚚 Способ получения: …
```

API принимает новые поля `wantedDate` (`YYYY-MM-DD`) и `urgent` (boolean); способ `taxi` с адресом уже поддерживается сервером.

## Правка заказа в боте (lib/telegram-bot.ts)

- Кнопка «✏️ Доставка» заменяется на «✏️ Изменить» (меню доставки больше не нужно: способ меняется в шаблоне).
- По нажатию бот присылает (force_reply, как сейчас) шаблон текущих данных в моноширинном блоке (копируется тапом):

```
Имя: Илья Красковский
Телефон: +373 60790351
Нужен к: 21.11
Срочно: нет
Способ: почта            (самовывоз | почта | nova poshta | такси | уточнит)
Индекс: 3300
Город: Тирасполь
Район: Тирасполь
Улица: Мечникова 31
Отделение:               (для Nova Poshta)
Адрес:                   (для такси)
```

- Разбор по названию поля (регистр и порядок не важны, `Поле: значение`); удалённые строки = без изменений; пустое
  значение у необязательного поля (Улица) очищает его.
- Проверки с понятным ответом в чат (как сейчас, предупреждение исчезает само): неизвестный способ, не хватает
  обязательного поля для способа, дата не в формате `ДД.ММ` (год — ближайший будущий). Ограничений «не раньше» для
  менеджера нет.
- Подпись пересобирается из полей; сохраняются заголовок, блок второго брелка, языковая пометка, источник, заметки,
  история. В историю: `🕒 15.11 14:02 · ✏️ Изменено: телефон, дата`.
- Если способ сменился между самовывозом и отправкой — заказ переезжает в нужную тему (как сейчас в `applyCaption`).
- Разбор старых подписей (до этого изменения, в т.ч. формат `🏘 Тирасполь, р-н Тирасполь`) — по возможности;
  то, что не распознано, менеджер впишет в шаблон.

## Ограничения

- Без базы данных: состояние заказа = подпись сообщения в Telegram (лимит 1024 символа, уже обрабатывается `appendLine`).
- Next.js 16 + React 19, Tailwind; без новых зависимостей (календарь — нативный `<input type="date">`).
- Тексты RU и RO.

## Оставлено исполнителю

- Точный вид «таблеток» и календаря в рамках текущей дизайн-системы (`#FFC400`, `#191715`).
- Вёрстка шаблона и тексты подсказок бота.

## Замечено попутно (вне объёма)

- Верные часы самовывоза — 12:00–21:00 (как на сайте); «09:00–23:00» было только в старых подписях заказов.
- Подпись «Poșta Moldovei · 2–4 дня» на кнопке способа стоит согласовать с новыми сроками.
