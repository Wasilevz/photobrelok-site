# Шаблоны почтовых бланков

- `ramburs.pdf` — «Formular Trimitere ramburs» (27.03.2024), `tfp3.pdf` — «Formular TFP-3» (25.11.2024).
  Официальные бланки с сайта Poșta Moldovei (xlsx), переведены в PDF LibreOffice'ом без изменений.
  Верхняя половина листа — пустой бланк, нижняя — образец заполнения; координаты полей в `../layout.ts`
  сняты с образца (`pdftotext -bbox`). Если почта обновит бланк — перегенерировать PDF и сверить координаты.
- `LiberationSans-Bold.ttf` — шрифт Liberation Sans (SIL Open Font License 1.1): латиница с ș ț ă î â и кириллица.
